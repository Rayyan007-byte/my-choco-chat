# 🍫 Choco Chat
A real-time chat application built with **React, Node.js, MongoDB, and Cloudinary** for image uploads.
---
## 📖 Description
Choco Chat is a modern chat app where users can:
- Register and login
- Upload avatars
- Create private and group chats
- Send messages in real-time
- Store images in Cloudinary
---
## 🚀 Features
- User authentication (JWT)
- Profile with avatar upload
- Cloudinary integration for storing images
- Local image fallback support
- Private and group chats
- Real-time chat updates using Socket.IO
- Responsive UI using Tailwind CSS
---
## 🛠 Tech Stack
- **Frontend:** React, Tailwind CSS, React Router  
- **Backend:** Node.js, Express  
- **Database:** MongoDB, Mongoose  
- **Cloud Storage:** Cloudinary *(fallback to local storage if unavailable)*  
- **Authentication:** JWT
